 # 🎵 Global Music Streaming Trends Analysis

## 📌 Project Overview

This project analyzes global music streaming listener preferences
to identify trends in music genres, streaming platforms, listener
demographics, subscription types, and listening behavior.

The project combines Python-based Exploratory Data Analysis (EDA)
with an interactive Power BI dashboard.

## 🎯 Objectives

- Identify the most popular music streaming platforms
- Analyze music preferences across age groups
- Identify popular genres and artists
- Compare Free vs Premium users
- Analyze listening patterns by time of day
- Explore regional music streaming trends
- Understand listener engagement and behavior

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI
- DAX

## 📊 Dataset

The dataset contains 5,000 records and 12 attributes related to
listener demographics, streaming behavior and music preferences.

Key variables include:

- Age
- Country
- Streaming Platform
- Top Genre
- Minutes Streamed Per Day
- Number of Songs Liked
- Most Played Artist
- Subscription Type
- Listening Time
- Discover Weekly Engagement
- Repeat Song Rate

## 🔍 Analysis

The Python notebook performs:

- Data cleaning
- Exploratory Data Analysis
- Distribution analysis
- Correlation analysis
- Visualization
- Insight generation

## 📈 Power BI Dashboard

The Power BI dashboard provides interactive visualizations
